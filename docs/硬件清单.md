## 避坑（这几条踩了就白花钱）

1. **ESP32-S3 一定买带 PSRAM 的 N16R8** —— 买成 N8R2 或没 PSRAM 的版本，音频直接跑不动。
2. **别买 "ESP32-CAM"** —— 那是老的 ESP32（不带 S），算力不够，而且引出脚少。
3. **树莓派 Zero 2W 是 micro USB 供电**，不是 Type-C，电源别买错。
4. **麦克风要数字的（I2S/USB）** —— 模拟麦接 ESP32 需要额外 ADC，很难做。
5. **屏幕认准 SPI 接口 + 具体型号**（ST7789 / ILI9488 / ST7796），型号不对驱动要自己调。
6. **别买电池方案** —— 桌面设备一直插电，省这笔钱和一堆充电/功耗问题。

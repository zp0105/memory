# 换电脑：U 盘搬家说明

> 这套东西**可以搬**，不是绑死在原电脑上。跟着做就行。

---

## 一、先看清哪些必须搬

| 拷什么 | 大小 | 为什么必须 |
|---|---|---|
| `D:\DHS\.cache\pylibs` | 5.1 GB | **手工装的 Python 库**（torch 那一套），重装极其磨人 → 必须拷 |
| `D:\DHS\voice`（不含 models） | ~1.3 GB | 网关代码、参考音频、**她的日记和记忆**（`voice\out`） |
| `D:\DHS\.wxwork` | 850 MB | 微信机器人、ASR 模型、桥 |
| `D:\DHS\.dsh` | 392 MB | **她的人格技能**（persona / memories） |
| `%LOCALAPPDATA%\dsh-py` | 1.5 GB | Python 解释器本身 |
| `D:\DHS\voice\models` | 7.6 GB | TTS/形象模型 —— **可省，但新机要重下几个 GB，建议一起拷** |
| ~~`D:\DHS\.cache\whl`~~ | ~~4.9 GB~~ | **别拷**，纯粹是下载缓存 |

**U 盘至少 32 GB**（全拷约 17 GB）；只有 16 GB 就按"精简模式"拷（约 9.4 GB，模型新机重下）。

---

## 二、要准备的东西

**旧电脑**
- 一个 U 盘（32 GB 推荐）
- 运行 `打包到U盘.cmd <U盘盘符>`（见第四节）

**新电脑**（提前装好这些）
1. **NVIDIA 显卡驱动**（[nvidia.cn](https://www.nvidia.cn/drivers/) 下对应型号）—— **最关键**
2. **微信 4.x** 客户端（装上先别登录也行）
3. 确保有 **D 盘**（这套东西所有路径都写的是 `D:\DHS`）

> ⚠️ **没有 NVIDIA 独显的新电脑**：语音对话基本用不了（合成一句话要等很久）。
> 微信聊天、写日记、手机推送仍然正常（那些靠云端 API）。

---

## 三、两个敏感点（脚本会自动处理）

| 敏感点 | 现在 | 不对会怎样 |
|---|---|---|
| **用户名** | `su` | `run.cmd` 里写的是 `%LOCALAPPDATA%\dsh-py\python.exe`。新电脑用户名不同 → 脚本会把 `dsh-py` 装到**新用户名**下，并自动改写 `run.cmd` |
| **盘符** | `D:` | 所有路径都写死 `D:\DHS`。新电脑没有 D 盘 → 脚本会报错并告诉你怎么改 |

---

## 四、操作步骤

### 第 1 步（旧电脑）：打包到 U 盘

双击或命令行：

```
D:\DHS\迁移包\打包到U盘.cmd  E:
```

（`E:` 换成你 U 盘的实际盘符，在"此电脑"里能看到）

- **默认精简模式**（不拷模型，约 9.4 GB）
- 想连模型一起拷：加 `/full`
  ```
  打包到U盘.cmd E: /full
  ```

### 第 2 步（新电脑）：装

把 U 盘插到新电脑，运行：

```
<U盘>\迁移包\新机安装.cmd  E:
```

（同样把 `E:` 换成 U 盘盘符）

它会自动：
1. 把文件拷到 `D:\DHS` 和新用户名的 `AppData\Local\dsh-py`
2. **检查并修正 `run.cmd` 里的路径**
3. 重建计划任务「日记」（每天 22:00）
4. 自检：Python 能不能跑、CUDA 是否可用、模型齐不齐、依赖缺不缺

### 第 3 步：验证

```
D:\DHS\voice\run.cmd D:\DHS\voice\gateway.py --text --say "你叫什么"
```

看到她说出人设名字就成了。

## 五、装完之后要做的（脚本会提示）

1. **装微信并登录**，然后跑一次 `wx-run.ps1 activate` 打开可访问性门，再启动微信机器人
2. **推送不用重配**：`voice\notify.json` 已经跟着搬过去了（Server酱 key + 邮箱授权码都在里面）
3. **模型如果没拷**：用 `voice\fetch_sd.py`、`voice\fetch_gsv.py` 重下（各 2 GB 左右）

## 六、常见问题

**Q：能两台电脑都用吗？**
能跑，但**记忆是本地文件**，两边会各记各的（不会自动同步）。真想两边同步，得把记忆文件放到网盘同步目录里——现在没做。

**Q：换电脑后她的记忆还在吗？**
在。`voice\out\session.jsonl`（对话记录）、`inner_state.json`（她的状态）、`memory.json`（长期记忆）、`diary\`（日记）都在 `voice\out` 里，跟着搬。

**Q：U 盘拷要多久？**
17 GB 大概 10–25 分钟（看 U 盘速度）。

**Q：能不搬 Python 环境、在新电脑重装吗？**
可以，但**不建议**：这套环境当初为绕开各种依赖坑手工打过补丁（transformers 版本检查绕过、tokenizers 降级、torch 校验……），重装要重踩一遍。直接拷最省事。

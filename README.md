# 回忆 · HuiYi

> 一个跑在自己电脑上的 AI 陪伴框架。她能听你说话、用你指定的音色回答、记得住你说过的事，
> 还能每天写一篇日记推到你手机上。

**数据全部在本地**（只有大模型推理走 API）。人设、记忆、语音参考都由你自己提供——
本仓库**不含任何真人数据**。

## 语音引擎：按硬件自动挑

| 引擎 | 设备要求 | RTF（实测） | 首块延迟 | 音色 |
|---|---|---|---|---|
| CosyVoice2-0.5B | NVIDIA 显卡 | ~1.0 | 2.6–3.4s | 零样本克隆 |
| **GPT-SoVITS** | **纯 CPU 也行** | **1.33** | 1.7–8.1s | 零样本克隆 |
| Edge TTS（微软） | 能联网即可 | 1.13 | ~1.7s | 预置音色 |
| CosyVoice2 | 纯 CPU | **7.7** ❌ | 16.4s | — |
| GPT-SoVITS | RTX 4060 | 0.32 | — | 零样本克隆 |
| CosyVoice2 + JIT | —— | **0.36 ❌ 反而更慢** | 12.8s | — |

> ### 最有价值的一条实测结论
> **同样跑在 CPU 上，GPT-SoVITS 比 CosyVoice2 快约 6 倍**（RTF 1.33 vs 7.7）。
> 原因是架构差异：GPT-SoVITS 是 VITS（轻），CosyVoice2 是 0.5B 大模型（重）。
> **所以没有独立显卡的机器，用 GPT-SoVITS 一样能跑出克隆音色。**
>
> 测试环境：i7-13650HX（14 核 20 线程）。测试时务必用
> `CUDA_VISIBLE_DEVICES=-1` 真正藏起显卡——**空字符串 `""` 不等于隐藏**，
> 我们第一次测试就是栽在这上面，整组数据作废。

## 两个工程上的坑（都踩过，解法在代码里）

### 1. RTF ≈ 1 时播放会"断粮"，听感像卡顿 + 吐字不清

合成速度和播放速度一样快（1.0x）时，音频队列迟早会空。
听起来像"说话一顿一顿、还吐字不清"，但 **ASR 回读的 CER 只有 0.02~0.06——字根本没吞**，
纯粹是断流造成的错觉。

解法：**开口前先攒够一点缓冲**（默认 2.5 秒，`--prebuf` 可调），
用一点延迟换整段流畅。实测：攒 1.0s 会断 11 次，攒 2.5s 断 0 次。

### 2. 打断机制会把她自己掐断

她说话时麦克风会收到自己的声音（回灌）。靠声学相关性判断不可靠——
实测回声相关系数最高只到 0.81，够不着门限，于是"她自己的声音"频繁触发误打断。

解法：**检测到"有人说话"时先暂停 250ms 再听一次**——
她声音停了就不响了；如果还有人在说，那才是真人在插话。
这个办法对声学延迟漂移免疫，比调门限稳得多。

## 快速开始

```bash
# 1. 依赖
pip install -r requirements.txt

# 2. 配置
cp config/config.example.json config/config.json
#    改成本机路径、填大模型 API key

# 3. 写人设 —— 这是"她是谁"
#    照 persona/example.md 的格式写：性格、说话习惯、共同记忆

# 4. 跑
run.cmd core/gateway.py                 # 语音对话（自动挑引擎）
run.cmd core/gateway.py --tts gsv       # 强制 GPT-SoVITS（要自己准备模型）
run.cmd core/gateway.py --tts edge      # 强制云端 Edge TTS（最省事）
run.cmd core/gateway.py --text --say "在干嘛"   # 只出文字，不合成（验证用）
```

**只想先看效果？** 用 `--tts edge --text`，不需要显卡、不需要下模型，能立刻跑通。

```
docs/       硬件清单、换电脑迁移、踩坑记录
persona/    人设模板（example.md）
config/     配置模板
```

## ⚠️ 关于克隆声音

**本项目不含任何真人声音数据。** 用之前请想清楚：

- **声音属于人格权**。未经本人同意克隆、使用、传播他人声音，
  可能违法，也可能**真的伤害到那个人**。
- 仓库里的 `persona/example.md` 是**虚构人物**，不是真人。
- 拿它做自己的私人陪伴，是你的事；**把别人的声音数据公开出去，是另一回事**。
